# usage-band

A mod for Claude Code and the Claude desktop app. It adds a dim line above the input box:

`5h: 23.5% used, 76.5% left, resets in 1h 0m  ·  7d: 40% used, 60% left, resets in 2d 5h  ·  session $1.23`

It also writes the same text to the status line. Remaining is shown as percent left per limit window; the API gives no dollar balance.

## Install

```
/plugin install usage-band --marketplace momonekomata/claude-usage-band
```
